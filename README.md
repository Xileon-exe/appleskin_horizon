# AppleSkin for Horizon

A port of [AppleSkin](https://github.com/squeek502/AppleSkin) (by squeek502, The Unlicense) to
[Horizon](https://github.com/horizon-rust/horizon), as a WebAssembly `.hmod` mod written in Rust.

See `NOTICE.md` for credits. Build: `cargo horizon-mod build --wasm`, then `cargo horizon-mod check`.
Install the file `target/horizon-mod/appleskin.hmod` from the launcher's Mods page.
